**NovaAI – AI SaaS Dashboard**

Developed a modern and responsive AI SaaS Dashboard as part of my internship at **SQRock IT Solutions**. NovaAI is designed as a centralized platform that brings multiple AI-powered productivity tools together with a clean, user-friendly interface.

**Key Features:**
• Responsive landing page with hero, features, AI tools, pricing, FAQ, testimonials, and contact sections
• Login, Signup, and Forgot Password interfaces
• Interactive dashboard with statistics, recent activity, and navigation
• AI Chat interface with model selection and conversation UI
• AI Image Generator with prompt, style, aspect ratio, and quality options
• AI Code Generator supporting multiple programming languages
• Text Summarizer with summary length and writing-style options
• Email Generator for different purposes, tones, and lengths
• Blog Generator interface
• Generation History with search, copy, and delete options
• User Profile with account information, statistics, security, and activity
• Settings with appearance, notifications, security, and account preferences
• Free, Basic, and Premium pricing plans
• Dark/Light mode
• Responsive mobile navigation
• Interactive buttons, loading states, copy functionality, and toast notifications

**Technologies Used:**
HTML5, CSS3, JavaScript, Responsive Web Design, LocalStorage

Through this project, I gained practical experience in developing a **multi-page SaaS platform**, creating responsive and reusable UI components, implementing JavaScript interactions, managing browser-side preferences using LocalStorage, and designing interfaces for different AI-powered tools.

This project helped me understand how dashboards, authentication interfaces, AI tool pages, pricing, profile management, settings, and responsive navigation can be combined into a consistent SaaS product experience.
